



4. Prosedur Testing 
Task 1  
Pengguna diminta memperbarui nama, telepon, dan alamat pada halaman profil lalu menyimpan perubahan data.
Dimulai:
Saat tester berada di halaman utama aplikasi dan sudah login ke akun.
Langkah Task:
1.	Tester membuka menu profil atau akun. 
2.	Tester mengubah data diri seperti nama atau email. 
3.	Tester menyimpan perubahan data. 
Diakhiri:
Saat perubahan data berhasil tersimpan dan informasi terbaru ditampilkan pada halaman profil.

Task 2 Pengguna diminta menambahkan metode pembayaran baru pada halaman payment method.
Dimulai:
Saat tester berada di halaman utama aplikasi dan sudah login ke akun.
Langkah Task:
1.	Tester membuka menu payment method atau metode pembayaran. 
2.	Tester memilih opsi tambah metode pembayaran baru. 
3.	Tester mengisi informasi metode pembayaran yang diperlukan. 
4.	Tester menyimpan metode pembayaran yang telah ditambahkan. 
Diakhiri:
Saat metode pembayaran baru berhasil tersimpan dan ditampilkan pada daftar payment method.

Task 3 Pengguna diminta mencari event Anta Show menggunakan fitur search bar pada aplikasi.
Dimulai:
Saat tester berada di halaman utama aplikasi.
Langkah Task:
1.	Tester menemukan fitur search bar pada aplikasi. 
2.	Tester mengetik kata kunci “Anta Show” pada search bar. 
3.	Tester melakukan pencarian event. 
4.	Tester memilih event yang muncul pada hasil pencarian. 
Diakhiri:
Saat event “Anta Show” berhasil ditemukan dan halaman detail event berhasil ditampilkan.

Task 4  Pengguna diminta menentukan jenis tiket, memilih kursi, lalu menyelesaikan proses pemesanan tiket.
Dimulai:
Saat tester berada di halaman pemilihan kursi atau pemesanan tiket.
Langkah Task:
1.	Tester memilih kursi yang tersedia. 
2.	Tester menentukan jenis tiket yang diinginkan. 
3.	Tester mengonfirmasi detail pemesanan tiket. 
4.	Tester menyelesaikan proses pemesanan. 
Diakhiri:
Saat sistem menampilkan notifikasi atau halaman bahwa pemesanan tiket berhasil dilakukan.

Task 5  Pengguna diminta membuka dan melihat detail tiket yang telah berhasil dipesan.
Dimulai:
Saat tester berada di halaman utama aplikasi setelah berhasil melakukan pemesanan tiket.
Langkah Task:
1.	Tester membuka menu tiket saya atau e-ticket. 
2.	Tester memilih salah satu tiket yang telah dipesan. 
3.	Tester melihat detail tiket seperti jadwal, kursi, dan status pemesanan. 
Diakhiri:
Saat detail tiket berhasil ditampilkan secara lengkap pada aplikasi.
